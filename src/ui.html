What do you want to do with this image?

Drop an image here

PNG, JPG, WebP, GIF, BMP or SVG. You can also paste an image (Ctrl+V) or open a file. The app splits the image into flat color areas, traces Bézier curves and looks for the best quality / size trade-off to fit in 15,360 bytes.

  • 1 file when possible without visible loss, otherwise as few files as possible.
  • Stacked layers: file 1 at the bottom, the next ones on top, same frame.
  • SVG accepted: an existing SVG (gradients, transparency, large file) is redrawn as a GT7-compatible version.
  • Gradients when it helps: GT7 shows linear and radial gradients but ignores opacity.

In GT7

  1. Import each SVG with the decal upload tool on gran-turismo.com (My Page). Limit: 15,360 bytes, hence the split.
  2. In the livery editor, place file 1 (bottom layer) and set size and position.
  3. If there are several files: Duplicate the layer, then Replace the decal with file 2 — same position, same size, perfect alignment. Repeat in order up to the last one.
