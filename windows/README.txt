VEKTOR — image to SVG for Gran Turismo 7 decals

Install / repair / uninstall
  Double-click Vektor-Setup.exe.
  - If Vektor is not installed: “Install” button.
  - If it is already installed: “Update” (or “Repair”), “Uninstall”, “Open Vektor”.
  Installed for your account only, without administrator rights:
    %LOCALAPPDATA%\Programs\Vektor
  Shortcuts: Start menu (always) and desktop (optional).
  Vektor also shows up in Settings → Apps → Installed apps
  (Modify = repair, Uninstall = uninstall).
  If Windows shows “Windows protected your PC”: More info → Run anyway
  (the program is not digitally signed).

  From the command line:
    Vektor-Setup.exe /quiet               silent install
    Vektor-Setup.exe /uninstall /quiet    silent uninstall

Usage
  1. Open, drop or paste (Ctrl+V) an image (PNG, JPG, WebP, GIF, BMP or SVG).
  2. Pick the image type, the number of colors and the quality.
     Palette: click a swatch = change the color; ⇄ = swap two colors
     (or drag a swatch onto another); eye = remove the color.
  3. Download the SVGs (15,360 bytes max each, the Gran Turismo site limit).

In GT7
  Import each SVG with the decal upload tool on gran-turismo.com.
  Place file 1, then for each following file: Duplicate the layer → Replace the decal.
  All files share the same frame: alignment is perfect.

Vektor opens in its own window (WebView2, built into Windows 10/11).
Everything is processed on your PC: no image is sent over the Internet.
